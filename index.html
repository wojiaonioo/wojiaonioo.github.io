TorchOcean：可微 GPU 海洋数值模式TorchOcean: a differentiable GPU ocean model

参照 MITgcm 用 PyTorch 重写的可微海洋环流模式，梯度能穿过整段积分传回，神经网络因此可以嵌在时间步里在线训练。

A differentiable ocean general circulation model rewritten from MITgcm in PyTorch. Gradients pass through the whole integration, so a neural network can sit inside the time step and be trained online.

结构Architecture

模式支持区域、全球经纬度和立方球网格，静力和非静力方程，以及开边界、KPP 垂向混合和潮汐强迫。代码约 12 万行 Python 和 1.4 万行 CUDA C++，3500 多次提交。

The model runs regional, global latitude–longitude and cubed-sphere grids with hydrostatic or nonhydrostatic equations, open boundaries, KPP vertical mixing and tidal forcing. The code is about 120,000 lines of Python and 14,000 lines of CUDA C++, with more than 3,500 commits.

一个时间步分五个阶段，神经网络作为组件嵌在其中，反向传播按相反顺序经过同样的阶段。执行分四层，最底层是纯 PyTorch 参照实现，编译、CUDA kernel 和多进程区域分解三层可以分别开关，开与不开只差舍入误差。

A time step has five stages, with the neural network as one component inside them; backpropagation passes through the same stages in reverse. Execution has four layers. The bottom one is a plain PyTorch reference; compilation, CUDA kernels and multi-process domain decomposition can each be switched on or off and change results only by rounding.

性能Performance

图 3 是 960×960×90 网格上的双精度静力模拟。同一算例从 PyTorch 直接执行时的每步 786 毫秒降到 161 毫秒，主要做了三件事。

Figure 3 is a double-precision hydrostatic simulation on a 960×960×90 grid. The same case went from 786 ms per step under plain PyTorch execution to 161 ms. The main work was:

  • 重构时间步代码，解决 torch.compile 的编译碎片和每步重编译。原先每步碎成 131 段、6 个函数退回未编译执行，改造后整步只在求解器处断开，稳态不再重编译。 Restructuring the time step so torch.compile no longer fragments it or recompiles every step. A step used to break into 131 pieces with 6 functions falling back to uncompiled execution; now it breaks only at the solver and stops recompiling once warm.
  • 手写 43 个 CUDA kernel，把 KPP 混合、隐式垂向平流、示踪物平流和水平黏性的多步计算各合并成一个 kernel。KPP 边界层深度计算的 kernel 启动从 2786 次降到 2 次，比 PyTorch 实现快 80 倍以上。其中 6 个 kernel 带手写反向。 Writing 43 CUDA kernels that fuse the multi-step computations of KPP mixing, implicit vertical advection, tracer advection and horizontal viscosity into one kernel each. The KPP boundary-layer depth went from 2,786 kernel launches to 2 and runs more than 80 times faster than the PyTorch version. Six kernels have hand-written backward passes.
  • 解决编译器重排通信导致的多卡死锁。 Fixing a multi-GPU deadlock caused by the compiler reordering communication.

单卡每格点每步 3.3 纳秒，与 GPU 海洋模式 Oceananigans 同一量级。两张卡的并行效率随网格增大而提高（图 4）。

A single GPU spends 3.3 ns per cell per step, the same order as the GPU ocean model Oceananigans. Two-GPU efficiency rises with grid size (Figure 4).

梯度计算中，检查点按显存余量放在显存或主机内存，求解器的反向改用隐式微分。480×456×90 网格单卡 100 步的梯度从 421 秒降到 30 秒，约为模拟耗时的 4 倍。

For gradients, checkpoints go to GPU or host memory depending on free space, and the solver is differentiated implicitly. A 100-step gradient on a 480×456×90 grid on one GPU went from 421 s to 30 s, about four times the simulation time.

混合建模与资料同化Hybrid modeling and data assimilation

  • 用 337 个参数的神经网络替换底摩擦公式，在线训练后恢复出了生成真值所用的公式，测试期损失降到训练前的 1/498。 Replaced the bottom-drag formula with a 337-parameter neural network; online training recovered the formula used to generate the truth and cut the test loss to 1/498 of its value before training.
  • 把 KPP 垂向混合换成神经网络，只用温盐观测训练，测试期温度误差降低 80% 至 88%，并分析了这类观测能约束哪些混合参数。 Replaced KPP vertical mixing with a neural network trained only on temperature and salinity observations; test-period temperature error fell by 80% to 88%, and I analyzed which mixing parameters such observations can constrain.
  • 用自动微分代替手写伴随做 4D-Var，同样设置下代价函数和 MITgcm 伴随模式一样降到初值的约 1/11.7；区域孪生试验同化后温度误差降低 81%。 Ran 4D-Var with automatic differentiation instead of a hand-written adjoint; under the same settings the cost function falls to about 1/11.7 of its initial value, as with MITgcm's adjoint. In a regional twin experiment, assimilation reduced temperature error by 81%.
  • 南海试验中反演底摩擦系数，误差从 20% 降到 5.1%；用 Ocean Station Papa 站的实测温度剖面估计表面热通量修正。 Inverted the bottom-drag coefficient in a South China Sea experiment, reducing its error from 20% to 5.1%, and estimated a surface heat-flux correction from measured temperature profiles at Ocean Station Papa.

下一步计划耦合 WRF 大气模式，构建可微海气耦合模式，并在此基础上发展 AI 混合 4D-Var 同化。

Next, I plan to couple the WRF atmospheric model into a differentiable ocean–atmosphere model and build hybrid AI 4D-Var assimilation on it.

与 MITgcm 的对齐精度Agreement with MITgcm

  • 在 MITgcm 的 Fortran 源码中插桩，输出时间步内各阶段的中间变量，逐阶段比对。6 个 MITgcm 官方算例全部通过，其中 5 个积分 600 步后与 MITgcm 逐位一致。 Instrumented MITgcm's Fortran source to write the intermediate fields of every stage and compared them stage by stage. All 6 official MITgcm test cases pass, and 5 of them stay bit-for-bit identical to MITgcm after 600 steps.
  • 全球 50 天模拟的梯度与 MITgcm 用 Tapenade 生成的伴随模式逐点比较，23.8 万个控制变量上最大归一化差为 5.5×10−11。 Compared the gradient of a 50-day global simulation point by point with MITgcm's Tapenade-generated adjoint: the largest normalized difference over 238,000 control variables is 5.5×10−11.
  • 建立验证矩阵，按算例和卡数检查模拟结果、梯度、性能和显存，取代了原有的 7450 项单元测试。 Built a verification matrix that checks simulation results, gradients, speed and memory for each case and GPU count, replacing the former 7,450 unit tests.
  • 对照 MITgcm 源码移植并对齐结果的过程中，发现了 MITgcm 自身的两处代码缺陷，已报告给官方。开边界海绵层南边界的盐度松弛时间用错了厚度（issue #989），修复 PR #990 已合并进官方代码；控制变量模块的时间插值权重写反（issue #1039），我提交的修复 PR #1040 已获维护者批准，等待合并。 Porting MITgcm and aligning results with it turned up two defects in MITgcm itself, which I reported upstream. The salinity relaxation time on the southern open-boundary sponge used the wrong thickness (issue #989); the fix, PR #990, is merged into MITgcm. The time interpolation weights in the control-variable package were swapped (issue #1039); my fix, PR #1040, is approved by a maintainer and awaiting merge.
